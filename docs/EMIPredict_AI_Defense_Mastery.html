Traditional rule engines evaluate each new loan application in isolation, completely blind to how cumulative leverage pushes the borrower's total Debt-to-Income (DTI) ratio over the 40% default cliff.

Q4 • ML Tournament

Why did XGBoost beat Random Forest and Logistic Regression?

Rubric: Model Selection Justification Flip 🔄
10-Second Model Answer

Random Forest averages parallel deep trees (reducing variance but bounded by base tree bias). XGBoost fits sequential trees to residual gradients using 2nd-order Taylor series with built-in $L_1/L_2$ regularization on leaf weights.

Mnemonic #1 • Preprocessing P - R - E - P

P — Partition First (stratified split before anything else)

R — Range Capping (IQR Winsorization at 1st & 99th percentiles)

E — Encoding & Imputation (Median for numbers, Mode for categories)

P — Pipeline Standard (ColumnTransformer fit strictly on Train)

Mnemonic #2 • FinTech Ratios D - E - F - S

D — Debt-to-Income (current_emi / salary < 40%)

E — Expense-to-Income (living obligations / salary)

F — Free Cash Flow (Salary minus Rent, Fees, Utilities, Debt)

S — Score (Composite 0-100 Financial Health Index)

1. XGBoost 2nd-Order Taylor Objective

Obj^{(t)} = \sum_{i=1}^{n} [ g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i) ] + \gamma T + \frac{1}{2} \lambda \sum_{j=1}^{T} w_j^2

• $g_i$ = first gradient; $h_i$ = Hessian; $\lambda$ = L2 leaf penalty.

2. ANOVA F-Statistic Ratio

F = \frac{\text{MSB}}{\text{MSW}} = \frac{\text{Between-Group Variance}}{\text{Within-Group Variance}}

• Confirmed distinct group means ($p < 0.001$) across eligibility classes.
